# 🌿 Plant Disease Prediction App

A machine learning-based application that detects and classifies plant diseases from leaf images. The app analyzes uploaded images and predicts whether the plant is healthy or affected by a disease, enabling early diagnosis and timely intervention.

The project uses image processing and deep learning techniques to identify plant diseases with high accuracy. It is designed to assist farmers, gardeners, and researchers in monitoring plant health and improving crop productivity.

## Features
- Disease detection from leaf images
- Classification of healthy and diseased plants
- User-friendly interface
- Fast and accurate predictions
- Supports multiple plant disease categories

## Applications
- Smart agriculture
- Crop health monitoring
- Precision farming
- Agricultural research

## Technologies Used
- Python
- TensorFlow/Keras
- OpenCV
- Flask/Streamlit
- NumPy
